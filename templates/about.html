About Hotel Management System

A modern hotel booking and management platform

📌 Project Overview

Hotel Management System is a web-based application developed using Django to simplify hotel booking, room management, and customer handling.

The system allows users to browse hotels and rooms, make bookings, complete online payments, and download GST invoices.

🚀 Key Features
  • User Registration & Login
  • Hotel & Room Listings
  • Online Room Booking
  • Secure Online Payments
  • GST Invoice Generation
  • Booking Status Tracking
  • Admin Panel for Management
🛠️ Technologies Used
  • Python & Django Framework
  • HTML, CSS & Bootstrap
  • SQLite / MySQL Database
  • Razorpay Payment Gateway
